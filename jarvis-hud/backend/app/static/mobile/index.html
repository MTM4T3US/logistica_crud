PAREAR ESTE CELULAR

No PC: Configurações → Sistema → Celular → “Parear celular”. Leia o QR com a câmera ou digite o código.

O celular recebe uma chave só dele; o PC guarda apenas uma impressão dela e você pode remover o aparelho no HUD a qualquer momento.
